Music Playlist Manager

A simple music playlist management system using LinkedHashSet.

Features

* Add a song
* Remove a song
* Check if a song exists
* Show the playlist
* Show song count
* Exit the system

Topics Covered

* LinkedHashSet
* Scanner
* while loop
* switch
* add()
* remove()
* contains()
* isEmpty()
* size()
* Enhanced for loop

LinkedHashSet prevents duplicate songs while keeping the insertion order of the songs.

Technologies

* Java
* Collections
* LinkedHashSet
* Scanner
